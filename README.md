# 網走湖 漁場ナビ

スキャンした漁場の地図に、スマホの GPS で現在地を出すページ。いちばん近い場所の名前（例：タンジ（1））を上に大きく出す。

- 開き方：GitHub Pages など https のアドレスで Safari から開く（位置情報は https でないと使えない）
- 位置合わせ：「位置合わせ」を押し、分かる場所（漁港・河口・ボート岬など）にいるとき地図のその場所をタップ。離れた2〜3か所で合う。記録は iPhone の中（Safari）に残る
- 「合わせた点をコピー」でチャットに貼ってもらえば、最初から合った状態の版にできる
- 場所の名前の位置は `index.html` の `ZONES`（地図画像の画素の位置）
- 地図：`map.jpg`（ユーザーから受け取ったスキャン・11/19）
